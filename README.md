# H题车载平衡滚球运动控制系统

本仓库只实现 H 题中的滚球视觉与滚球控制接口：MaixCAM 检测单颗钢球、估计位置和
速度、管理滚球目标，并通过 UART 单向发送给 MCU。底盘相关实现不在本仓库范围内。

负责滚球执行器接入的队友请先阅读 [`docs/MCU_HANDOFF.md`](docs/MCU_HANDOFF.md)。

## 功能

- YOLO11n 单球检测；只把 `x=0..319, y=87..150` 的 320×64 轨道区域送入模型，
  检测结果仍须通过更严格的 `x=8..312, y=96..142` 有效区门限。
- 两点投影标定，将图像坐标换算为摆杆一维厘米坐标。
- alpha-beta 滤波估计位置与速度；漏检只预测 100ms，随后发送无效测量。
- 检测通道使用单缓冲，避免处理排队旧帧。发送前按“半帧曝光时间 + 实际推理时间”
  外推位置，补偿上限 100ms；状态栏 `L` 显示本次使用的测量年龄。
- 三种滚球目标：中点平衡、三点、触屏定点。
- 摄像头请求 `320x240@90fps`；MaixCAM Pro 的 OS04A10 会切换到 720p90
  传感器模式，其他传感器可能按硬件能力降帧。推理和 UART 逐帧运行，屏幕、图传
  和录像共用一张 15fps 标注帧；界面用紫色十字标记当前目标点，日志中的
  `runtime FPS` 为实际处理帧率。
- UART 为 `115200 8N1`，只发送位置误差与速度，不传模式。

## 标定和触屏操作

摄像头必须刚性固定。建议以 `-10cm` 和 `+10cm` 两点标定：

1. 把球放到 `-10cm`，检测稳定后按 `CAL-L`。
2. 把球放到 `+10cm`，检测稳定后按 `CAL-R`。
3. 在 `0cm`、`±5cm` 复核，位置误差应小于 `0.3cm`。

按钮：

| 按钮 | 功能 |
|---|---|
| `CAL-L` / `CAL-R` | 保存左右标定点 |
| `MODE` | `CENTER -> 3-POINT -> FIXED` |
| `START` | 在 `3-POINT` 模式下开始或重新开始三点序列 |
| `T-` / `T+` | 按当前步长减/加定点目标，范围 `-100..+100mm`，并进入 `FIXED` |
| `5MM` / `1MM` | 切换定点快调 5mm 与细调 1mm；按钮文字显示当前步长 |
| `EXIT` | 退出应用 |

定点目标内部使用整数毫米保存，避免连续细调产生浮点累计误差。状态栏以 `T:+3mm`
格式显示目标；UART 中的误差仍按整数毫米发送，无需修改 MCU 协议。

三点模式进入后先显示 `3PT-WAIT`，目标保持 `0cm`。按 `START` 后目标立即切到
`+5cm`；球进入 `+5cm` 的 ±`1.5cm` 区域后立即切到 `-5cm`，不检查速度、不等待。
在 `-5cm` 位置误差不大于 `1.5cm` 且速度不大于 `2cm/s` 并稳定 500ms 后，保持
该目标并显示 `DONE`。这样 MCU 只需持续使用误差和速度，不需要知道目标或阶段。

## UART 协议

帧固定为 11 个 ASCII 字节：

```text
[ E E E E V V V V * ]
  \---error---/ \-velocity-/
```

- `EEEE`：`ball_error_mm = target_mm - position_mm`。
- `VVVV`：`ball_velocity_mm_s`。
- 数值固定为符号加三位十进制数字，范围 `-999..+999`。
- 示例：`[-110+045*]`。
- 无效测量：`[NaN NaN *]`，两个字段必须同时无效。
- 无 CRC；解析器使用固定长度、帧头 `[` 和帧尾 `*]` 重新同步。

MaixCAM A16(TX) 接 MCU RX，双方共地。协议解析见
[`mcu_reference/vision_protocol.c`](mcu_reference/vision_protocol.c)。

## Wi-Fi、图传和录像

先退出应用，在 MaixCAM 系统设置中手动连接热点，再重新启动本应用。应用不会修改
系统网络配置；触屏左上角只显示 `NET IP地址` 或 `NET OFFLINE`。

电脑接入同一热点后，浏览器打开 `http://触屏显示的IP:8080`。监控页可开始/停止
录像；停止后录像出现在下载列表。正在写入的 AVI 不允许下载，退出应用时会自动
收尾保存。MJPEG 图传端口固定为 `8000`，浏览器管理端口固定为 `8080`。

不要把 8080/8000 端口暴露到不可信网络。录像不会自动删除，比赛前应检查存储
空间并通过 SSH 清理应用目录下的 `recordings/`。

## 编译与运行

```bash
MAIXCDK_PATH=/path/to/MaixCDK maixcdk build -p maixcam
./build/h_ball_balance ./models/stainless_ball.mud /dev/ttyS0 \
  ./balance_calibration.cfg ./recordings
```

应用启动器会自动使用包内模型。未连接 MCU 时可把串口参数改为 `none`。

## 滚球 PID 整定

1. 限制摆杆角度，确认误差、速度和执行器方向。
2. 令 `Ki=0`，从较小的 `Kp` 开始。
3. 增大 `Kp` 到响应足够快，再增加 `Kd` 抑制超调。
4. 最后只加入很小的 `Ki` 消除静差，并保留积分和输出限幅。
5. 先验证 `0cm`，再验证 `+5cm`、`-5cm` 和定点模式。

`mcu_reference/control_core.c` 只包含平台无关的滚球 PID、使能和视觉失联保护；PWM、
UART DMA 与具体执行器 HAL 由 MCU 工程接入。参考增益必须在实物上重新整定。
